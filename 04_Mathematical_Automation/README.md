markdown# Discrete Mathematics Infrastructure Engines

This module contains low-level implementations of mathematical foundations from Rosen's *Discrete Mathematics* and Lewis & Papadimitriou's *Elements of the Theory of Computation*.

### Architectural Application
* **Power Set Generation:** Used to calculate all possible multi-tenant access permission combinations to model firewall traffic rule paths. Done from scratch using bitwise manipulation to maintain zero library dependencies.
* **Set Algebra (Union/Intersection/Complement):** Used to programmatically isolate subnet overlaps, fabric clashes, and unique paths across dual multi-homed BGP internet gateways without using standard high-level macros.
